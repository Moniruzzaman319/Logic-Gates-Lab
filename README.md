# Sifath Gates Lab

An interactive, responsive digital logic learning lab covering Modules 1–4.

## Modules
1. Basic logic gates
2. Universal gates (NAND and NOR)
3. Boolean algebra laws
4. Adders, flip-flops, and counters

## Run locally
Open `index.html` in any modern browser. This is a static HTML/CSS/JavaScript project and needs no build step.

## Deploy with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. After GitHub finishes publishing, the site will be available at:
   https://moniruzzaman319.github.io/Sifath-Gates-Lab/
